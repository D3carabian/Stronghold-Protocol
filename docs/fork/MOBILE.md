# 手机、iPad 与 Safari 验收

上游已经有触摸拖放、长按、横屏提示、安全区域、添加到主屏幕以及 Safari 的启动检测。
当前页面明确要求 iOS/iPadOS 16.4+ / Safari 16.4+（原生 import maps）。这只是技术下限，不是所有机型的性能保证。
资源不需要按 Windows、iOS 各部署一套；服务端导出为网页可用的图片、模型和音频。

## 必测场景

每次重大渲染或认证更新，在测试服记录设备型号、系统版本、浏览器、代码提交和资源版本。
覆盖 iPhone Safari 横屏、iPad Safari 横屏、Mac Safari、桌面 Chrome。至少一次使用真实移动网络。
不要用 Chromium 手机尺寸截图代替 Safari 实测。

1. 登录、刷新、Cookie、WebSocket 建连，不能出现循环登录；未来邮箱链接从邮件 App 返回 Safari 的行为也要测。
2. 首屏字体和素材加载，无缺图；购买、拖放、长按、装备、滚动、横竖屏切换和安全区。
3. 用户点按后才开始音频；静音/解除静音、切后台再回来、锁屏后恢复。
4. 完整单人对局，以及双设备合作、失联重连；触摸应避免误缩放、页面拖拽和误购买。
5. 3D 场景的帧率、发热与内存；`?board=2d` 验证 2D 路径，`?render=fallback` 验证降级入口。
6. 新版本上线后的缓存刷新与旧页面提示，不得混用旧脚本、新数据和另一版本素材。

## 当前证据边界

部署阶段检查 HTTP、媒体 MIME/Range、WebSocket、资源清单和桌面界面。真正的 iPhone/iPad Safari
完整对局需设备验收，尚不能标记为通过。Windows 导出工具也需要在实际客户端上首次验证。
不预先压缩所有纹理或改格式；先测出瓶颈，再在测试服做兼容性改进。

2026-10-12：Chrome 经测试隧道进入 3D 棋盘；Mac Safari 经同一隧道完成首屏加载、连接与进入大厅。
外网接口测试确认音频分段请求返回 206。尚未验证 Safari 公网 Basic Auth、完整作战、触摸和后台恢复。
