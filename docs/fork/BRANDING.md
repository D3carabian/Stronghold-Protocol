# 网页图标

游戏和邮箱登录页共用 `public/icons/community-logo-*.png`。32/192 用于浏览器图标，180 用于 Apple
主屏幕图标，192/512 用于 Web App manifest。完整标志来自所有者提供的活动横幅，使用内置 imagegen 清理，
作为本社区站点的品牌图标；不是整包游戏素材导入。不改变原有非官方同人、非商业声明。

处理提示：提取横幅左侧完整 logo，保留白色点阵塔形、横向底座、STRONGHOLD PROTOCOL、绿色 ALLIANCE
以及“卫戍协议：盟约”；去除地图、TARGET POINT、扫描线、箭头和活动日期；在深绿黑色正方形背景上居中，
保留安全边距，无圆角、阴影或额外文字。生成后以标准图像导出工具缩放为网站所需尺寸。

浏览器图标路径使用新的 community-logo 文件名，避免沿用旧缓存。认证服务只公开这四张图标和 manifest；
游戏资源仍需登录。上游旧图标保留供参考，没有被覆盖；当前 HTML 和 manifest 都引用新图标。
