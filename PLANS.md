# Execution plans

For multi-step features, deployment changes and substantial refactors, keep a self-contained plan in
`docs/fork/plans/`. Describe the user-visible outcome, current context, intended file changes, milestones,
exact verification commands, rollback and unresolved inputs. Maintain Progress, Discoveries, Decisions and
Outcomes as work proceeds. Record measured results, not intended results. A future contributor should be able
to continue using the plan and repository without a chat transcript.

This adapts OpenAI's AGENTS.md guidance and execution-plan recipe; it is a project convention, not a claim that
OpenAI mandates this directory layout. Sources: https://learn.chatgpt.com/docs/agent-configuration/agents-md
and https://developers.openai.com/cookbook/articles/codex_exec_plans .
